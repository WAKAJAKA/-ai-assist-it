# Todo API Service

REST API-сервис для управления пользователями и задачами (todo), написанный на Go с использованием фреймворка Chi.

## Возможности

- CRUD операции для пользователей (создание, получение, обновление, удаление)
- CRUD операции для задач (создание, получение, обновление, удаление)
- Swagger-документация (OpenAPI 3.0)
- Валидация входных данных

## Стек технологий

- **Язык**: Go
- **Роутер**: Chi v5
- **Документация**: swaggo (Swagger UI)

## Структура проекта

```
├── internal/
│   ├── handlers/     # HTTP-хендлеры (todo.go, user.go)
│   └── models/       # Модели данных (todo.go, user.go)
├── docs/             # Сгенерированная Swagger-документация
├── main.go           # Точка входа
└── README.md         # Документация проекта
```

## Запуск

```bash
go run main.go
```

Сервер запустится на **http://localhost:8080**

## Swagger UI

Документация API доступна по адресу:
**http://localhost:8080/swagger/index.html**

## API Endpoints

### Пользователи (Users)

| Метод   | Маршрут         | Описание                    |
|---------|-----------------|-----------------------------|
| GET     | /api/v1/users   | Получить список всех пользователей |
| POST    | /api/v1/users   | Создать нового пользователя |
| GET     | /api/v1/users/{id} | Получить пользователя по ID |
| PUT     | /api/v1/users/{id} | Обновить пользователя |
| DELETE  | /api/v1/users/{id} | Удалить пользователя |

### Задачи (Todos)

| Метод   | Маршрут          | Описание                    |
|---------|------------------|-----------------------------|
| GET     | /api/v1/todos    | Получить список всех задач  |
| POST    | /api/v1/todos    | Создать новую задачу        |
| GET     | /api/v1/todos/{id} | Получить задачу по ID     |
| PUT     | /api/v1/todos/{id} | Обновить задачу           |
| DELETE  | /api/v1/todos/{id} | Удалить задачу            |

## Генерация Swagger-документации

```bash
swag init
```

- `docs/docs.go`
